PERFTHUB

perfthub is a tool that lets you perft test the milochess chess engine. it provides a cli that lets you interact with all its features. 

by default, 3 .log files are generated for each test run:
- perfthub_info -  basic information about the test 
- perfthub_error -  detailed information about failed tests 
- perfthub_full -  all information about each test 

they are stored in {milochess_executable_path}/perfthub/{test_date} directories, created dynamically.

-h, --help

print help (this very document).


-l, --loose

omit testing against expected values, outputting the results the files anyway. be sure to pass the flag if your perft.txt file doesn't include expected values of the test to avoid errors 


-d, --depth

pass the maximum depth of the test, skipping being prompted to do so later.


-t, --tests 

pass the amount of positions to be tested, skipping being prompted to do so later.
